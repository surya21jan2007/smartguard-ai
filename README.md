# SmartGuard AI 🚨

AI-based real-time CCTV theft detection system.

## Features
- Motion Detection
- Human Detection (YOLOv8)
- Theft Detection Logic
- Telegram Alert System
- Evidence Image Saving

## Tech Stack
- Python
- OpenCV
- YOLOv8
- Telegram Bot API

## Run
pip install -r requirements.txt
python src/camera_theft_system.py
